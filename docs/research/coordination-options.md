# Transport options: consult when blocked

Status: nonblocking reference. The human's latest instruction removes a comparative framework study as a prerequisite. The first prototype is a local CLI invoked by human-launched Codex sessions, so no provider adapter has to be chosen before building.

## Reversible default now

Use one local Workboard module with a CLI, persisted state, and small file-based reports. Prefer an already installed standard-library runtime. Research only a missing capability that prevents the next working step. Record the answer in the implementation handoff rather than commissioning a survey.

## Prior primary-source findings

Sources originally checked 2026-09-26, America/Vancouver. These are documentation observations, not tests on the owner's machine.

- [Codex non-interactive documentation](https://developers.openai.com/codex/noninteractive/) describes programmatic execution, structured output, and session resumption. Relevant when Foundry must execute agents rather than just coordinate already launched sessions.
- [Codex SDK](https://developers.openai.com/codex/sdk/) and [app-server](https://developers.openai.com/codex/app-server/) describe richer integrations. Verify the installed version before using either. They are not needed for this first slice.
- [Codex MCP](https://developers.openai.com/codex/mcp/) is a possible way to expose coordination tools later. Codex acting as an MCP client is distinct from older removed Codex-as-MCP-server recipes.
- [Symphony at be10a1b](https://github.com/openai/symphony/blob/be10a1b79df723d6d7612b5651c8522704dafb2e/README.md) and its [specification](https://github.com/openai/symphony/blob/be10a1b79df723d6d7612b5651c8522704dafb2e/SPEC.md) are adoption/reference candidates for automated dispatch. The prior inspection covered the README and first 180 specification lines, not implementation validation.
- [SQLite usage guidance](https://www.sqlite.org/whentouse.html) informs the single-host choice. No network-shared database file is proposed.

## Trigger for future research

When the working slice lacks a needed capability, answer one question: what is the smallest supported way to add it while preserving human launches, identifiable sessions, fresh review, and stop control? Compare only credible alternatives for that question. Stop when a reversible choice or explicit blocker is established.
