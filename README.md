# Dream Foundry

A human-directed Codex swarm for research, experimentation, and eventually executable art.

## Bootstrap status

The repository is being prepared for a small, local, CPU-only precursor swarm. Planning and agent launch briefs are being developed on a separate documentation branch; no controller or workers are running yet.

The first milestone is reliable research, evidence, independent review, and restartable coordination. GPU workloads, model downloads, unattended spending, deployment, and automatic merges are outside the initial scope.

See the repository's pull requests for the proposed foundation package.
